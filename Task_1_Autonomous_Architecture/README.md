# Task 1: Autonomous Architecture

## Objective

The objective of this task is to select the most suitable sensor and flight computer architecture for an autonomous drone.

The selected architecture will be evaluated based on:

- Autonomous capability
- Processing capability
- Power consumption
- Weight
- Cost
- Reliability


## Sensor Architectures Considered

The following five architectures are evaluated:

1. Stereo Camera + NVIDIA Jetson Orin Nano

2. Depth Camera + Raspberry Pi 5

3. LiDAR + Raspberry Pi 5

4. Stereo Camera + Raspberry Pi 5

5. Intel RealSense D435i + NVIDIA Jetson Orin Nano


## Final Selection

The final architecture will be selected after comparing all parameters using a weighted decision matrix.
